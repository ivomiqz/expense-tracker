Expense Tracker
Expense Tracker — это  веб-приложение для учёта личных расходов.
С помощью приложения можно:
1. Добавлять расходы.
2. Выбирать категорию: еда, транспорт, развлечения или другое.
3. Смотреть список расходов.
4. Фильтровать расходы по категории.
5. Удалять расходы.
6. Смотреть график расходов по месяцам.
 Как работает проект
Проект состоит из двух частей: 'client' и 'server'.
'client' — это frontend на React и TypeScript. Здесь находится форма, список расходов и график.
'server' — backend на Node.js и Express. Он получает запросы от frontend и работает с базой данных.
Для хранения расходов используется 'sql.js'.
Основные запросы:
1. 'GET /api/expenses' — получить расходы.
2. `POST /api/expenses` — добавить расход.
3. 'DELETE /api/expenses/:id' — удалить расход.
Также в проекте есть проверка данных, сообщения об ошибках и загрузка данных.
